## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18.0.0 or later) and `npm` installed.

### Installation

1. **Clone or open the repository:**
   ```bash
   git clone https://github.com/Sritharan2005/Sritharan-3D-Portfolio-VSCode.git
   cd Sritharan-3D-Portfolio-VSCode
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. Open the localhost URL displayed in your terminal (typically `http://localhost:5173`) to view the application.

---

## 📦 Production Build

To compile and optimize the application for deployment:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

- **Contact Details**: Update email, phone numbers, and WhatsApp links in `src/ContactSection.jsx` and `src/main.jsx`.
- **Resume**: Replace `public/Sritharan-Resume.pdf` with your updated resume PDF.
- **Visual Styles & Colors**: Adjust CSS variables and glowing color themes in `src/styles.css`.
